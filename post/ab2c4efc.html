AXI4协议是什么

AXI4（Advanced eXtensible Interface 4）是 Arm 公司 AMBA（高级微控制器总线架构）第四代规范中的核心片上总线接口协议，专为高性能、高带宽、低延迟的片上系统（SoC）与 FPGA 设计而制定。它通过独立的通道架构、突发传输与握手协议，高效连接处理器、内存控制器及各类 IP 模块。

核心类型与变体

  • AXI4（AXI4-Full）：支持最长 256 拍的突发传输（Burst），用于处理器与 DDR 内存等高吞吐量数据交互。
  • AXI4-Lite：精简版协议，仅支持单次传输（突发长度为 1），结构简单，常用于配置控制寄存器和低速外设。
  • AXI4-Stream：面向无地址映射的连续数据流传输（如视频、音频、高速 ADC/DMA 数据流），不支持传统读写地址与突发长度限制。

五大独立通道与握手机制

AXI4 将读、写操作拆分为五个相互独立的通道，便于时序优化与并行处理：

  1. 读地址通道（AR）：主机发送读取目标地址及控制信息。
  2. 读数据通道（R）：从机返回读取的数据及读响应状态。
  3. 写地址通道（AW）：主机发送写入目标地址及控制信息。
  4. 写数据通道（W）：主机发送写入的数据与字节选通掩码（WSTRB）。
  5. 写响应通道（B）：从机在一次写突发完成后返回写入结果状态。

各通道均采用 VALID / READY 握手机制：当发送方 VALID 与接收方 READY 同时为高电平时，当前时钟沿完成一次数据传输。
