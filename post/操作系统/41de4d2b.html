linux嵌入式中的uevent是什么?

发表于2026-11-24|更新于2026-11-25|操作系统
|浏览量:

基本概念

udev 事件（在内核中称为 uevent）是 Linux 内核在硬件设备状态发生变化（如插入、拔出、属性修改）时，通过 Netlink 套接字主动发送给用户空间守护进程（udev / mdev / systemd-udevd）的异步通知消息。

为什么存在

在早期的 Linux 中，/dev 目录下静态存放着成千上万个设备节点文件，无论硬件是否真实存在。引入 udev 机制后，/dev 变成了完全动态的：

  • 动态创建与销毁设备节点：当你把一个 U 盘插到嵌入式开发板上，内核识别到硬件后会发送一个 ACTION=add 的 udev 事件；用户空间的 udevd 收到后，才会动态在 /dev 下创建 sda1 节点，拔出时再自动删除。
  • 自动配置权限与软链接：udevd 接收到事件后，会根据 /etc/udev/rules.d/ 中的规则文件，自动修改设备节点权限（如 chmod 0666）或创建固定名称的别名（如 /dev/ttyUSB_GPS）。
  • 触发自动化脚本：硬件接入或状态变化时，通知上层业务程序启动（例如检测到网线插入后自动执行 DHCP 获取 IP，或者插入 SD 卡后自动挂载）。

udev 事件的工作流程

  1. 事件触发（内核态）：驱动程序调用 device_register() 注册设备，或者主动调用 kobject_uevent() 接口。
  2. 发送消息（Netlink）：内核将事件打包成包含多个环境变量的字符串，通过 NETLINK_KOBJECT_UEVENT 广播出去。
  3. 接收与匹配（用户态）：后台运行的守护进程（如桌面/大型嵌入式常用的 systemd-udevd，或 BusyBox 轻量级嵌入式常用的 mdev）监听到该消息，读取其中的环境变量，并与本地规则库逐条比对。
  4. 执行动作：规则匹配成功后，执行创建 /dev 节点、修改属主或运行指定 Shell 脚本等操作。
